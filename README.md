# Iris Flower Classification Using AI

## Project Overview
This project classifies Iris flowers into three categories:
- Setosa
- Versicolor
- Virginica

## Technologies Used
- Python
- Scikit-Learn
- Matplotlib
- Colorama

## Algorithms Used
- Decision Tree Classifier
- K-Nearest Neighbors (KNN)

## Features
- Dataset Loading
- Train-Test Split
- Accuracy Comparison
- Classification Report
- Confusion Matrix
- User Prediction
- Menu Driven Interface
- Accuracy Graph

## Dataset
Iris Flower Dataset (150 samples)

## Output
The model predicts flower species based on flower measurements.
